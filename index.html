Panduan Super Admin

Cara Update Database & Sinkronisasi ke Semua User

Halaman ini khusus Super Admin. Ikuti langkah berikut agar pembaruan data otomatis tampil sama di semua pengguna & semua perangkat.

Prinsip 1
1 Sumber Data

Semua data tersimpan di GitHub (Cloud). Tidak ada data yang “nyangkut” di satu komputer.

Prinsip 2
Publish = Commit

Sekali Anda Publish, file di GitHub ter-update dan semua user membaca versi itu.

Prinsip 3
Auto-Sync

User lain cukup buka / klik “Muat ulang”. Tidak perlu instal apa pun.

Langkah Update — Monitoring JUBELIO

A. Update data Monitoring

  1. Buka menu Monitoring JUBELIO.
  2. Pada panel Update Database, unggah file Excel dari folder Infinity:
    • JUBELIO - Sales.xlsx (wajib)  • AdminLPH.xlsx  • TransferInDetail_MM_HO.xlsx  • SAP - Sales.xlsx
  3. Klik Proses & Publish ke Cloud.
  4. Masukkan PIN Publish (default 10111976).
  5. Tunggu proses selesai — muncul “✓ dipublish ke Cloud”. Data langsung tersimpan di GitHub.
Langkah Update — Sales Database

B. Update data Sales

  1. Buka menu Sales Database.
  2. Unggah Data Utama (daftar penjualan barang).xlsx (wajib) dan file tujuan bila ada: YTD, Template, MTD.
  3. Klik Proses & Publish ke Cloud → masukkan PIN Publish.
  4. Hasil (dengan pivot yang dipertahankan & auto-refresh) tersimpan di Cloud dan bisa diunduh semua user.
Agar Semua User Melihat Data yang Sama

C. Sinkronisasi lintas perangkat

  1. Setiap kali Anda Publish, data ter-commit ke repo GitHub — inilah “sumber kebenaran” tunggal.
  2. User lain tidak perlu upload apa pun. Mereka cukup membuka alamat dashboard yang sama.
  3. Saat halaman dibuka, aplikasi otomatis menarik data terbaru dari Cloud. Untuk memaksa refresh, klik ↻ Muat ulang (atau Muat ulang semua di Overview).
  4. Semua perangkat (PC, HP, tablet) yang membuka URL yang sama akan melihat data & tampilan identik dengan yang Anda publish.
  5. Cek menu Update Data Status untuk memastikan tanggal data sudah yang terbaru.
Peran & Keamanan

D. Siapa bisa apa

Super Admin (Anda): upload, proses, publish, kelola Berita Acara.
Viewer (user lain yang Daftar): hanya melihat data & unduh — upload/edit terkunci.
PIN Publish (ADMIN_PIN) diperlukan tiap kali publish data. PIN akun Anda diperlukan untuk edit Berita Acara.
Token GitHub tersimpan aman di Vercel — tidak pernah tampil di browser atau di repo.

Bila Ada Masalah

E. Troubleshooting cepat

  1. Muncul peringatan “mode lokal” / data tidak tersimpan → buka /api/health, pastikan github = OK.
  2. Publish gagal → biasanya PIN Publish salah, atau token GitHub perlu izin Contents: Read and write.
  3. Data user belum berubah → minta mereka klik ↻ Muat ulang atau refresh halaman.
